## 🏦 About

**FinDoc AI** is a RAG-based AI agent developed for the INFORM × UniAI Makeathon 2026. It processes invoices, receipts, and financial documents — answering user questions based strictly on document content while providing visual proof (bounding-box highlights) of where each answer was found.

### Key Features

| Feature | Description |
|---------|-------------|
| 🎯 **Accurate Q&A** | Grounded answers strictly from document content |
| 🖼️ **Visual Evidence** | Highlighted bounding boxes showing the exact source |
| 🛡️ **Zero Hallucinations** | 4-layer anti-hallucination system |
| 📊 **Auto-Summary** | Instant document analysis on upload |
| ⚠️ **Smart Alerts** | Detects anomalies and flags issues |
| 🟢 **Confidence Scores** | Visual confidence indicator per answer |
| 💬 **Follow-up Chat** | Conversation memory for multi-turn Q&A |
